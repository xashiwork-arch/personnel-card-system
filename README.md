# سامانه مدیریت کارت پرسنلی / یزدان مطهر قائم وسطی

سامانه جامع و متمرکز ثبت، پیگیری، و گردش کار ۶ مرحله‌ای صدور کارت‌های پرسنلی برای ۸ مجموعه با تفکیک کامل دسترسی و پیام‌رسانی داخلی.

---

## 🏢 شعب و مجموعه‌های تحت پوشش
1. **هایپر آرین** - مسئول: خانم رسولی
2. **هایپر قدمت** - مسئول: خانم رضوی
3. **مشتاق قائمشهر** - مسئول: خانم صباغی
4. **مشتاق آمل** - مسئول: خانم مهدی پور
5. **مشتاق بهنمیر** - مسئول: خانم باباجان زاده
6. **مشتاق نکا** - مسئول: خانم صادقی
7. **مشتاق ساری** - مسئول: خانم صباغی
8. **فروشگاه آرین** - مسئول: خانم صباغی

---

## 🔄 چرخه ۶ مرحله‌ای صدور
1. **۱. دیده نشده** 🟡 (در انتظار بررسی مدیریت)
2. **۲. دیده شده** 🔵 (بازبینی اولیه مدارک)
3. **۳. آماده‌سازی فایل** 🟣 (طراحی و اصلاح گرافیکی)
4. **۴. ارسال به لابراتوار** 🟠 (تولید فیزیکی)
5. **۵. چاپ شده** 🟢 (آماده‌سازی کارت)
6. **۶. تحویل داده شده** 💎 (تحویل نهایی به پرسنل)

---

## 🚀 راهنمای نصب و راه‌اندازی محلی

```bash
# نصب وابستگی‌ها
npm install

# اجرای برنامه
npm start
```

سایت روی پورت ۳۰۰۰ اجرا می‌شود: `http://localhost:3000`
